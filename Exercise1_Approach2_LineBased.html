This layout demonstrates Approach 2: Line-Based Positioning and Spanning using style2.css. Instead of declaring named regions in grid-template-areas, each child element directly targets start and end grid line numbers.

  • .header { grid-column: 1 / 4; } — Spans across all 3 column tracks.
  • .sidebar { grid-column: 1 / 2; grid-row: 2 / 4; } — Spans 2 row tracks vertically.
  • .main-content { grid-column: 2 / 4; } — Spans columns 2 and 3.
  • .widget-a { grid-column: 2 / 3; } & .widget-b { grid-column: 3 / 4; }
  • .footer { grid-column: 1 / 4; } — Full width bottom track.

📝 Notes on Both Approaches (Lab Manual Page 8):

  • If using grid-template-areas → usually use grid-area only.
  • If using line-based positioning → use grid-column and grid-row.
  • Mixing both is allowed, but typically not required.
