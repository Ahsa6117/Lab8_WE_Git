Rule: grid-template-columns: 240px 1fr 1fr; defines three columns.

2. Dynamic Row Sizing: minmax(300px, auto) (Page 6)

Rule: grid-template-rows: 70px minmax(300px, auto) 180px 50px;

  • Row height can never be less than 300px.
  • It can grow beyond 300px if content requires more space.
Scenario Content Height Resulting Computed Row Height Reasoning
Scenario A 250px 300px 250px is less than 300px minimum bound → clamped to 300px.
Scenario B 500px 500px 500px exceeds 300px minimum → expands dynamically via auto.

3. Auto-Fit vs Auto-Fill & Gutter Control (Page 7 & 16)

In Lab Task 1, repeat(auto-fit, minmax(250px, 1fr)) dynamically creates as many columns as will fit. Because auto-fit collapses empty tracks to 0px, all items stretch naturally across the viewport width.
